# osakatrip

오사카 가족 여행(2026-12-03 ~ 2026-12-07)용 **near-private** 모바일 웹 UI 골격입니다.  
공유 링크로만 열람하는 전제이며, 공개 마케팅 사이트가 아닙니다.

현재 턴: **로컬 예시 UI** (외부 API·로그인 없음). 화면의 「예시」/「샘플」 배너는 확정 예약·시간과 다를 수 있음을 표시합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 주소(기본 `http://localhost:5173`)를 엽니다.

```bash
npm run build    # 타입체크 + 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```

## 화면 (v1 셸)

| 경로 | 내용 |
|------|------|
| `/` | 여행 홈 |
| `/itinerary`, `/itinerary/:date` | 날짜별 일정 |
| `/packing` | 준비물 체크리스트 (체크는 localStorage) |
| `/usj` | USJ 준비 허브 (링크·메모) |
| `/places/:placeId` | 장소 상세 (스텁 + 예시 데이터) |
| `/transit`, `/transit/:transitId` | 교통 안내 (스텁 + 예시 데이터) |

하단 네비: 홈 · 일정 · USJ · 준비물

## 확정 컨텍스트

- 일정: 2026-12-03 ~ 2026-12-07 오사카
- 인원: 4 (초5 여아, 초3 남아 포함)
- USJ: Day 4 = 2026-12-06
- 접근: 공유 링크만 / PIN·로그인은 later
- 웹 편집·기기 동기화: later

## 하지 않음 (이 턴)

- 외부 API / API 키
- 로그인·PIN
- 영업시간·요금·티켓을 사실로 하드코딩
